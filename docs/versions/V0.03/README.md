# V0.03 初始入库基线

日期：2026-11-17。该基线对应正在实板测试的屏幕诊断固件，尚未确认正常显示。

- 主控STM32F429IGT6，180MHz；FMC SDRAM32MiB、90MHz/refresh683；LTDC RGB565、400×960，PCLK约27.1MHz，总450×1004。
- SSD2828 GPIO三线控制，ID/回读恢复后启动2lane、400Mbps/lane及GC9503厂家39包。
- 自动背景色/单帧对照及桥PCLK采样边沿对照；MCU极性、SDRAM时序和面板命令保持。
- 显示测试覆盖30步/两边沿、BG无帧访问、图层所有权、9图案、供电/39包、扫描/时基/回读/PLL/reload/帧/地址/边沿故障退出、tick回绕。
- SDRAM测试覆盖全容量16/32位、地址/字节、保持及屏蔽/频率/命令失败注入，原失败门槛保留。

`source_sha256.json`是原38文件的精确字节哈希；`sdk_sha256.json`是103个依赖文件的精确字节哈希。入库前后均需一致，原工程`.mxproject`另随源码纳入Git。当前新增的README/测试入口不属于历史38文件清单，正常由Git跟踪。

`firmware_sha256.json`记录交付`H863_V0.03_Release_20261117_1516`的HEX/BIN/ELF。ELF可能包含构建路径；同工具链新路径构建应优先核对BIN及HEX承载的内容。后续代码变更需更新版本，不要求永久匹配V0.03固定哈希。

实板状态：用户确认R111当前10kΩ；V0.02全容量自检及桥控制已通过，实拍图像失真。用户正在测试本版，记录和结论仍待回传。
